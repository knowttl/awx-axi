# Security

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/knowttl/awx-axi/security/advisories/new) when available.
If private reporting is unavailable, open an issue requesting a private contact channel without disclosing vulnerability details.
Never include tokens, passwords, private controller hosts, tenant data or unredacted logs in public reports.

Include the affected CLI version from `awx-axi --version`, a description of the impact and a minimal reproduction using synthetic data.
See [safety and permissions](docs/safety.md) and [credential handling](docs/credentials.md) for the CLI's security boundaries.
